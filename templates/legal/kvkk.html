{% trans "KVKK Aydınlatma Metni" %}

{% blocktrans %} FinAsis olarak 6698 sayılı Kişisel Verilerin Korunması Kanunu (“KVKK”) kapsamında kişisel verilerinizi güvenle işliyor ve saklıyoruz. Bu sayfa, veri işleme amaçlarımızı, saklama sürelerimizi ve haklarınızı özetler. {% endblocktrans %}

{% trans "Veri Sorumlusu" %}

{% blocktrans %} FinAsis Yazılım ve Danışmanlık A.Ş., KVKK uyarınca veri sorumlusudur. İletişim: kvkk@finasis.com.tr {% endblocktrans %}

{% trans "Veri İşleme Amaçlarımız" %}

  • {% trans "Hizmetlerin sunulması ve sözleşme süreçlerinin yürütülmesi" %}
  • {% trans "Mali işlem kayıtlarının tutulması ve mevzuata uyum" %}
  • {% trans "Müşteri desteği ve operasyonel süreçlerin yürütülmesi" %}
  • {% trans "Ürün geliştirme, kişiselleştirme ve analitik faaliyetleri" %}

{% trans "Saklama Süreleri" %}

{% blocktrans %} Kişisel veriler, ilgili mevzuatın öngördüğü minimum süre boyunca saklanır. Finansal kayıtlar için 10 yıl, destek talepleri için 3 yıl, pazarlama izinleri için silme talebine kadar saklama uygulanır. {% endblocktrans %}

{% trans "Haklarınız" %}

{% blocktrans %} KVKK madde 11 kapsamındaki haklarınızı kullanmak için kvkk@finasis.com.tr adresine imzalı dilekçe veya kayıtlı elektronik posta (KEP) yoluyla başvurabilirsiniz. Talebiniz en geç 30 gün içerisinde yanıtlanacaktır. {% endblocktrans %}

{% trans "Veri İşleme Güvenliği" %}

{% blocktrans %} FinAsis platformu; şifreleme (AES-256), erişim kontrolü, denetim logları, MFA/SSO ve coğrafi yedekleme gibi teknik ve idari tedbirler uygular. Anonimleştirme ve silme süreçleri için `manage.py retention_execute` komutları uygulanmaktadır. {% endblocktrans %}
