# Common (Ortak) Bileşenler

Bu klasör, projede uygulamalar arasında ortak kullanılabilecek permission, mixin, templatetag ve yardımcı fonksiyonları içerir.

## İçerik
- `permissions.py`: Ortak izin sınıfları
- `mixins.py`: Ortak model veya view mixinleri
- `templatetags/common_tags.py`: Ortak template filtreleri

Projede tekrar eden kodları burada toplamanız önerilir.
