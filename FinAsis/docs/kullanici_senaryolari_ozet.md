## 💎 Kullanıcı Tipi Geçiş Matrisi

Kullanıcılar bir tipten diğerine nasıl geçer?

```
┌─────────────────────────────────────────────────────┐
│                                                     │
│  ÖĞRENCI ──────────────────────► KOBİ              │
│     │         (Mezuniyet/İş kurma)                  │
│     │                                               │
│     │                                               │
│     └──────► OYUNCU ◄────────────┐                 │
│            (Gamification)         │                 │
│                 │                 │                 │
│                 │                 │                 │
│                 ▼                 │                 │
│            EĞİTİMCİ ──────────────┘                 │
│         (İçerik üretme)                            │
│                                                     │
└─────────────────────────────────────────────────────┘
```

**Geçiş Senaryoları:**

1. **Öğrenci → KOBİ** (En yaygın)
   - Mezuniyet sonrası kendi işini kurar
   - Öğrendiği bilgileri gerçek işletmede kullanır
   - %20 indirim ile KOBİ planına geçer

2. **Öğrenci → Oyuncu** (Retention stratejisi)
   - Ders çalışma motivasyonu düştüğünde
   - Oyun ile öğrenmeyi birleştirir
   - Puanları coin'e çevirir

3. **Oyuncu → Öğrenci** (Up-sell)
   - Oyunda öğrenmeye ilgi duyar
   - Sertifika almak ister
   - Freemium'dan öğrenci planına geçer

4. **Eğitimci ↔ KOBİ** (Dual role)
   - Hem eğitim veriyor hem işletme sahibi
   - Her iki modülü de aktif kullanır
   - Combo plan avantajı
