API Anahtarları ve İmza Doğrulama

En iyi uygulamalar:

  • API anahtarlarını istemci tarafında asla tutmayın; sunucu→sunucu çağrılar yapın.
  • Her isteği HMAC-SHA256 ile imzalayın: signature = HMAC(secret, method + "\n" + path + "\n" + timestamp + "\n" + body)
  • Başlıklarda X-API-Key, X-Timestamp (ISO8601/epoch), X-Signature gönderin.
  • Sunucu tarafında zaman kaymasını ±5 dk kontrol edin ve tek-kullanımlık nonce kabul edin.
Python (Django/Flask) doğrulama örneği 
import hmac, hashlib, time

def verify_signature(secret: str, method: str, path: str, timestamp: str, body: bytes, signature: str) -> bool:
    msg = f"{method}\n{path}\n{timestamp}\n".encode() + body
    calc = hmac.new(secret.encode(), msg, hashlib.sha256).hexdigest()
    return hmac.compare_digest(calc, signature)

Node.js (Express) doğrulama örneği 
const crypto = require('crypto');

function verifySignature(secret, method, path, timestamp, body, signature) {
  const msg = Buffer.concat([
    Buffer.from(`${method}\n${path}\n${timestamp}\n`),
    Buffer.isBuffer(body) ? body : Buffer.from(body || '')
  ]);
  const h = crypto.createHmac('sha256', secret).update(msg).digest('hex');
  return crypto.timingSafeEqual(Buffer.from(h), Buffer.from(signature || ''));
}
