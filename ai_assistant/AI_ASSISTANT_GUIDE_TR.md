## ✨ YENİ ÖZELLİKLER (v2.0)

### 1. **Sentiment Analysis** 😊😐😞
Müşteri geri bildirimlerini, e-postaları ve dokümanları analiz ederek duygu durumunu tespit eder.

**Kullanım:**
```
http://127.0.0.1:8000/ai-assistant/sentiment/
```

**Özellikler:**
- Türkçe sentiment detection
- Pozitif/Nötr/Negatif sınıflandırma
- Güven skoru (0-1)
- Anahtar kelime çıkarma
- Entity recognition (email, para, tarih)

**Örnek:**
```python
from src.apps.ai_assistant.services.sentiment_service import SentimentAnalysisService

result = SentimentAnalysisService.analyze_text(
    "Hizmetinizden çok memnunum, teşekkürler!"
)
# → {'sentiment': 'positive', 'confidence_score': 0.85, ...}
```

### 2. **Document Summarization** 📄
Uzun dokümanları otomatik özetler - extractive summarization.

**Kullanım:**
```
http://127.0.0.1:8000/ai-assistant/summarize/
```

**Özellikler:**
- Extractive summarization (önemli cümle seçimi)
- Sıkıştırma oranı hesaplama
- Ana nokta çıkarma
- Stop-word filtreleme
- Entity extraction

**Örnek:**
```python
from src.apps.ai_assistant.services.summary_service import DocumentSummarizationService

result = DocumentSummarizationService.summarize_text(
    text=uzun_metin,
    max_sentences=5
)
# → {'summary': '...', 'compression_ratio': 0.15, ...}
```

**Kullanım:**
```
http://127.0.0.1:8000/ai-assistant/reports/generate/
```

**Rapor Tipleri:**
- Günlük özet

- Çeyreklik inceleme
- Yıllık rapor

- Kar-zarar
- Gider analizi

**Örnek:**

### 4. **Advanced Analytics** 📈
Gelişmiş finansal analizler - tahmin, segmentasyon, pattern recognition.

**Kullanım:**
```
http://127.0.0.1:8000/ai-assistant/advanced/run/
```

**Analiz Tipleri:**
- Gelir tahmini (Revenue Forecast)
- Gider deseni (Expense Pattern)
- Müşteri segmentasyonu (RFM Analysis)
- Churn prediction
- Karlılık analizi
- ABC Analizi (Pareto)
- Cohort analizi
- Market basket

**Örnek:**
```python

```

## 📡 API Endpoints

### Sentiment Analysis API
```
POST /ai-assistant/api/sentiment/analyze/
Content-Type: application/json

{
    "text": "Hizmetiniz harika!"
}
```

**Response:**
```json
{
    "sentiment": "positive",
    "confidence_score": 0.85,
    "positive_score": 0.85,
    "neutral_score": 0.10,
    "negative_score": 0.05,
    "keywords": ["harika"],
    "entities": []
}
```

### Document Summarization API
```
POST /ai-assistant/api/summarize/
Content-Type: application/json

{
    "text": "Uzun doküman metni...",
    "max_sentences": 5
}
```

### Auto Report API
```
POST /ai-assistant/api/report/generate/
Content-Type: application/json

{
    "report_type": "daily_summary"
}
```

## 📊 Kullanım Senaryoları

### Senaryo 1: Müşteri Feedback Analizi
```python
# Tüm müşteri yorumlarını topla
feedbacks = CustomerFeedback.objects.all()

for feedback in feedbacks:
    sentiment = SentimentAnalysisService.analyze_and_save(
        text=feedback.comment,
        user=admin_user,
        source_type='customer_feedback',
        reference_model='feedback',
        reference_id=feedback.id
    )

# İstatistikleri al
stats = SentimentAnalysisService.get_sentiment_statistics(admin_user, days=30)
print(f"Pozitif: {stats['positive']}% Negatif: {stats['negative']}%")
```

### Senaryo 2: Sözleşme Özetleme
```python
# Uzun sözleşme metnini özetle
contract_text = open('sozlesme.txt').read()

summary = DocumentSummarizationService.summarize_and_save(
    text=contract_text,
    user=user,
    document_type='contract',
    max_sentences=10
)

print(f"Orijinal: {summary.original_length} kelime")
print(f"Özet: {summary.summary_length} kelime")
print(f"Sıkıştırma: %{(1-summary.compression_ratio)*100:.0f}")
```

### Senaryo 3: Aylık Raporları Otomatikleştir
```python
# Celery task ile aylık otomatik rapor
from celery import shared_task

@shared_task
def generate_monthly_reports():
    from django.contrib.auth import get_user_model
    User = get_user_model()
    
    for user in User.objects.filter(is_active=True):
        AutoReportGenerationService.generate_monthly_financial(user)
```

### Senaryo 4: ABC Müşteri Analizi

```python
# En değerli müşterileri tespit et
abc = AdvancedAnalyticsService.abc_analysis(user)

a_customers = abc.results['classification']['A']
print(f"A sınıfı (en değerli): {len(a_customers)} müşteri")
print(f"Toplam gelir %80'ini sağlıyorlar!")
```
